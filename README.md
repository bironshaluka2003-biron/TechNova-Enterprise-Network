# TechNova Enterprise Network Design & Implementation

## Project Overview

TechNova Solutions is a medium-sized enterprise with a three-floor headquarters and a remote branch office. This project focuses on designing and implementing a scalable enterprise network using Cisco Packet Tracer.

The network design includes departmental VLANs, IPv4 and IPv6 addressing, inter-VLAN routing, dynamic routing, network security, and multicast configuration.

## Technologies and Concepts

- Cisco Packet Tracer
- Cisco IOS router and switch configuration
- IPv4 addressing and Variable Length Subnet Masking (VLSM)
- IPv6 dual-stack configuration
- VLANs and trunking
- Router-on-a-stick inter-VLAN routing
- Dynamic NAT with Port Address Translation (PAT)
- Single-area and multi-area OSPF
- Layer 2 security, including DHCP snooping and port security
- IP multicast using PIM Sparse Mode concepts
- Network troubleshooting and connectivity testing

## Network Architecture

The simulated enterprise network consists of:

- Headquarters with three floors
- HR and Administration department
- Engineering and IT department
- Sales and Marketing department
- Server farm
- Remote branch office
- Four routers and multiple switches

## How to Explore the Project

1. Install Cisco Packet Tracer.
2. Clone or download this repository.
3. Open `TechNova_Enterprise_Network.pkt` in Cisco Packet Tracer.
4. Review the router and switch configuration files.
5. Refer to the project report for the addressing scheme, network design, and implementation details.
